# NetworkWalks — Cybersecurity Internship

**Weekly write-ups from my Cybersecurity Internship at Networkwalks (Batch B083).**

Each week gets its own folder with a README and screenshots covering what I did, what I found, and what I learned.

---

## 📂 Weeks

- **[Week 1 — Cybersecurity & Pentesting Lab Setup](week1/README.md)**
  Built a virtual cybersecurity testing lab with VirtualBox and Kali Linux, on an isolated NAT Network.

- **[Week 2 — Passive Reconnaissance & OSINT](week2/README.md)**
  Ran passive OSINT tools (WHOIS, WhatWeb, dnsrecon, curl, wafw00f) against networkwalks.com, with permission, to map out its public-facing footprint.

- **[Week 3 — Password Cracking](week3/notes.md)**
  Cracked a password-protected PDF two ways: with John the Ripper (JTR/Johnny) and with Networkwalks' own browser-based hash calculator and cracker tools.

- **[Week 4 — Penetration Testing Report](week4/README.md)**
  Chained an SQL injection auth bypass with weak PDF password cracking to access patient records, and separately found a leaked database backup exposing staff national IDs and shareholder equity.
